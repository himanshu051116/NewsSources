Too little context.

    04 / EVIDENCE, NOT CERTAINTY

    Knowing the source
    is not knowing the truth.

    NewsSources is built around inspectable records and reviewer judgment, not automated verdicts. This distinction matters when news outlets repeat the same report or a primary document changes.

    CAN SHOW

    Where a figure was reported

    Article versions, captured passages and their recorded source relationships.

    CAN HELP REVIEW

    Whether reporting shares a source

    A reviewer can inspect suggested lineage and disputed or revised claims.

    CANNOT GUARANTEE

    That a reported fact is true

    Real-world accuracy depends on source permissions, quality and independent editorial checks.

    05 / PROJECT NOTES

    Built for questions
    that deserve sources.

    The repository contains a Python FastAPI backend, PostgreSQL migrations, collection workers, HTML and PDF extraction, source-aware analysis, and an analyst reader. Its real-world editorial performance still needs independently reviewed evaluation.
